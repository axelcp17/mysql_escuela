\# Práctica de MySQL - Base de datos Escuela



En este proyecto creé la base de datos `escuela` en MySQL Workbench. Agregué las tres tablas que nos pidieron (`estudiante`, `profesor` y `materia`), configurando los campos con los tipos de datos requeridos (`INT`, `VARCHAR`, `CHAR` y `DECIMAL`).



Toda la explicación paso a paso y las capturas de pantalla están en el archivo \[evidencias.md](evidencias.md).
